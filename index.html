기록 저장·불러오기

기록은 이 브라우저에만 저장돼요. 다른 기기에서 이어서 풀려면 여기서 저장하고, 그 기기에서 불러오세요.

교안 장

    테이블 구조

    실습 데이터

    ‘실행’으로 만든 테이블이나 바꾼 데이터는 이 페이지를 닫을 때까지 남아요. 채점은 항상 처음 상태의 데이터로 해요.

    정말 지울까요? 이 기기에 저장된 답이 모두 사라져요.

    답을 쓰고 ‘채점하기’를 누르면 브라우저 안의 실습 데이터(S_EMP 25명, S_DEPT 11개 등)로 바로 실행해서 정답 결과와 비교해요. 컬럼 순서나 별명이 달라도 값이 같으면 정답이에요.

    DDL·권한·트랜잭션처럼 결과로 비교하기 어려운 문제는 ‘정답 확인’으로 모범 답안과 핵심 키워드를 보고 스스로 채점해요. 실행기는 오라클 문법을 흉내 내는 SQLite라 ROWNUM, PIVOT, ROLLUP, 권한 명령 등은 실행되지 않아요. 결과가 이상하면 오라클에서도 실행해 보세요.

    자바 기록은 이 브라우저에만 저장돼요. 다른 기기에서 이어서 풀려면 여기서 저장하고, 그 기기에서 불러오세요. SQL 기록과는 따로 저장돼요.

    교재 장

      내 기록

      정말 지울까요? 이 기기에 저장된 자바 답이 모두 사라져요.

      객관식과 출력 결과 문제는 답을 고르거나 쓰고 ‘채점하기’를 누르면 바로 채점돼요. 출력 결과는 실행했을 때 화면에 나오는 그대로 한 줄씩 쓰면 되고, 띄어쓰기만 다르면 정답으로 쳐요. 모든 출력 정답은 Java 21로 실제 실행해서 확인한 결과예요.

      모두 520문제이고 장마다 기초·응용·심화가 고루 있어요. 그중 직접 코드를 짜는 문제는 사용 예와 실행 결과가 함께 나와요. ‘Claude에게 채점받기’로 내 코드를 채점받거나, ‘연습장에서 실행’으로 직접 돌려 볼 수 있어요(import 문은 생략해도 돼요). 위의 난이도 버튼으로 골라 풀 수 있어요. 오른쪽 아래 { } 버튼을 누르면 Java 코드를 자유롭게 써 보고 실행 결과를 확인할 수 있는 연습장이 열려요.

      직접 작성 문제는 코드를 쓰고 ‘정답 확인’을 누르면 모범 답안과 핵심 키워드가 나와요. 비교해 보고 ‘맞았어요/틀렸어요’로 스스로 채점해요. 7~13장 문제는 목차 기반 개념 정리를 바탕으로 만들었어요.

      DB 모델링 기록은 이 브라우저에만 저장돼요. 다른 기기에서 이어서 풀려면 여기서 저장하고, 그 기기에서 불러오세요. SQL·자바 기록과는 따로 저장돼요.

      교안 장

        내 기록

        정말 지울까요? 이 기기에 저장된 DB 모델링 답이 모두 사라져요.

        객관식 문제는 보기를 고르고 ‘채점하기’를 누르면 바로 채점돼요. 강의 교안(1장 데이터 모델링 이론, 2장 개념 모델링, 3장 논리 모델링)과 수업 필기를 바탕으로 만들었고, 장마다 기초·응용·심화가 고루 있어요.

        서술·설계 문제는 답을 쓰고 ‘정답 확인’을 누르면 모범 답안과 핵심 키워드가 나와요. 비교해 보고 ‘맞았어요/틀렸어요’로 스스로 채점하거나, ‘Claude에게 채점받기’로 내 설계를 채점받을 수 있어요. 엔티티는 주문(주문번호 | 주문일자, 고객번호 FK)처럼 써도 돼요.

        Claude 연결

        claude.ai 밖(GitHub 페이지 등)에서 새 문제 만들기, Claude 채점, Java 연습장을 쓰려면 내 Anthropic API 키가 필요해요. 쓴 만큼 이 키의 계정에 요금이 나가요.

        • 키는 이 브라우저에만 저장되고, Anthropic API로만 보내요. 다른 사람과 같이 쓰는 컴퓨터에서는 넣지 마세요.
        • 키는 Anthropic 콘솔에서 만들 수 있어요. 콘솔에서 월 사용 한도를 정해 두면 안심이에요.
        • 새 문제는 Claude Haiku, 채점과 연습장은 Claude Sonnet을 써요. 쓴 금액은 콘솔의 사용량(Usage) 화면에서 볼 수 있어요.
